GitHub와 Firebase 역할
사이트 운영: Firebase Hosting / plant-book-84803.web.app
사진 분석 서버: Cloudflare Workers
코드 백업·변경 이력: GitHub 저장소
현재 방식에서 GitHub Pages는 필요하지 않습니다.
GitHub에 커밋/푸시하는 것만으로 현재 Firebase 사이트가 자동 업데이트되지는 않습니다.
별도 자동 배포를 설정하지 않았다면 아래 firebase deploy를 실행합니다.

바뀐 화면
- 내가 선택한 사진에 '내 관찰 사진' 표시.
- 각 식물 후보에 비교용 참고 사진 최대 2장 표시.
- 사진별 부위(잎·꽃 등), 촬영자, Pl@ntNet, 라이선스와 출처 표기.
- 참고 사진을 누르면 원본을 새 창으로 열어 비교할 수 있습니다.
- 한글 이름과 학명, 후보 점수, 후보 선택 상태를 표시합니다.
- 사진이 없거나 로딩 실패 시에도 이름으로 후보를 선택하고 저장할 수 있습니다.
- 320px의 좁은 화면에서는 참고 사진을 한 열, 넓은 휴대폰에서는 두 열로 배치합니다.

사진의 의미
비교 사진은 AI 후보를 이해하는 참고 자료이며, 식물 종의 확정 근거는 아닙니다.
내 도감에는 사용자가 고른 관찰 사진을 저장합니다.
참고 사진을 내 관찰 사진으로 대체하거나 Firestore에 복사하지 않습니다.
AI 선택 정보 저장 구조는 기존과 같습니다.

참고 사진 출처와 처리
Pl@ntNet 식별 요청에 include-related-images=true, nb-results=5를 적용했습니다.
별도 종 목록 사진 API(Pro 기능)는 사용하지 않습니다.
참고 사진은 Pl@ntNet 이미지 서버 https://bs.plantnet.org 에서 브라우저가 직접 불러옵니다.
호출 시 사용자의 IP 등 일반 접속 정보는 이미지 서버에 전달될 수 있습니다.
로그인 토큰과 Pl@ntNet 비밀 API 키를 이미지 주소에 넣지 않습니다.
DO 결과 캐시에는 사진 URL과 출처 정보가 포함되지만 사진 파일 자체는 저장하지 않습니다.
원본의 전체 비율을 유지해 표시하며, 이미지를 편집하거나 재배포 패키지에 포함하지 않습니다.
촬영자/허용되는 라이선스/공식 이미지 주소가 확인된 참고 사진만 표시합니다.
지원하는 참고 사진 라이선스: CC BY, CC BY-SA (전달된 버전은 그대로 표시).
다른 라이선스나 출처 누락 자료는 화면에서 제외하며 식별 후보는 유지합니다.

적용 전
기존 프로젝트 전체와 public-config.json을 백업합니다.
ZIP을 별도 폴더에 풀고 내용물을 기존 프로젝트 폴더에 적용합니다.
기존 .git을 유지하고 폴더가 중첩되지 않도록 합니다.
public-config.json에는 앞서 확인한 공개 Firebase 설정과 Worker 주소가 있습니다.
이후 직접 변경한 값은 자신의 백업 설정을 유지하세요.

1. Cloudflare 서버 배포
cd /d "C:\Users\김준태\Documents\GitHub\bangjangsan-plant-book\backend"
set "NODE_USE_SYSTEM_CA=1"
npm ci
npm test
npx wrangler deploy

기존 Pl@ntNet Secret은 그대로 이용합니다. 비밀 키 재발급/재입력은 필요하지 않습니다.
Cloudflare 로그인이 만료되었을 때만 npx wrangler login --device --browser=false 를 사용하세요.

2. 앱 빌드와 Firebase Hosting 배포
cd /d "C:\Users\김준태\Documents\GitHub\bangjangsan-plant-book"
set "NODE_USE_SYSTEM_CA=1"
npm ci
npm test
npm run build
firebase deploy --only hosting --project plant-book-84803

이번 변경으로 Firestore 규칙이나 기관·담당자 권한을 다시 배포하지 않습니다.
빌드는 참고 사진의 정확한 출처만 이미지 연결 허용 대상으로 추가합니다.
반드시 새 빌드 후 Hosting을 배포해야 합니다.

3. 휴대폰 확인
https://plant-book-84803.web.app 을 새로고침합니다.
로그인 → 사진 기록 → 사진 촬영/선택 → 전송 동의 → AI 식물 후보 분석.
후보별 참고 사진과 촬영자·라이선스 표시를 확인합니다.
사진을 누르면 원본이 새 창으로 열리는지 확인합니다.
후보 선택 후 이름 입력란을 확인하고 비공개 저장합니다.
내 도감 상세에 저장된 사진이 내 관찰 사진인지 확인합니다.

참고 사진이 보이지 않을 때
- 후보에 참고 사진이 없거나 출처/라이선스가 불충분할 수 있습니다.
- 외부 이미지 접속이 기관 네트워크에서 제한될 수 있습니다.
- 서버만 배포하고 앱을 다시 빌드/배포하지 않았다면 이미지 연결이 차단될 수 있습니다.
- 이전 버전에서 분석한 요청을 캐시로 재사용하면 사진 정보가 없을 수 있습니다.
  새 사진 선택으로 새 요청을 만들어 확인할 수 있지만 식별 호출 한도는 적용됩니다.
- 빈 사진 안내가 보여도 이름 선택과 수동 저장은 사용할 수 있습니다.

검증 범위
앱 테스트 46개와 서버 테스트 5개, 프로덕션 빌드, Worker dry-run을 확인했습니다.
React 정적 렌더링에서 참고 사진/출처/사진 없음 안내와 이미지 CSP를 확인했습니다.
서버 테스트의 Google/Pl@ntNet 응답과 사진 정보는 모의 데이터입니다.
실제 API 사진 반환, 외부 이미지 로딩, 실물 휴대폰 카메라/GPS/화면은 검증하지 못했습니다.
실제 Cloudflare/Firebase 배포는 사용자가 위 명령으로 진행합니다.
