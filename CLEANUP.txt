v44 파일 정리

이번 ZIP에서는 아래 31개 이전 파일을 제외했습니다.
예전 버전별 업데이트 안내를 USER_GUIDE.txt 하나로 합쳤습니다.
현재 로고를 사용하도록 홈 화면 추가 안내를 고치고, 이전 로고·아이콘·예시 이미지를 제외했습니다.
실행 코드·설정·검사·현재 원본 사진과 로고·법적 출처 표시는 유지했습니다.

기존 PC 폴더에서는 새 파일을 복사해도 예전 파일이 자동으로 지워지지 않습니다.
프로젝트 전체를 먼저 백업한 뒤 다음 명령을 사용하세요.
npm run cleanup
  대상 목록만 확인합니다. 아무 파일도 지우지 않습니다.
npm run cleanup -- --apply
  지정된 대상만 backup-cleanup/날짜-번호 아래에 원래 경로대로 백업한 뒤 지웁니다.
  먼저 모든 대상의 백업을 확인하며, 파일이 도중에 바뀌면 정리를 멈춥니다.
  목록에 없는 파일과 설정·식물 사진·현재 로고는 건드리지 않습니다.
  바로가기나 외부 폴더를 가리키는 파일은 정리하지 않습니다.
  백업은 나중에 직접 확인한 뒤 보관하거나 지워주세요.
새 ZIP만 푼 폴더라면 정리할 이전 파일이 없다고 나오는 것이 정상입니다.
node_modules는 설치 파일이고 dist는 배포 파일이므로 이 정리에서 제거하지 않습니다.
브라우저·Firebase에 저장한 이용자 기록도 삭제하지 않습니다.
