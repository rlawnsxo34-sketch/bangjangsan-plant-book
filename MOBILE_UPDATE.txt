1. 기존 파일 백업
기존 프로젝트 폴더를 다른 위치에 복사해 보관합니다.
public-config.json도 별도로 복사해 보관합니다.
기기 도감의 중요한 기록은 기존 백업 기능으로 JSON을 받아 둡니다.

2. 새 파일 적용
이 ZIP을 별도 폴더에 압축 해제합니다.
내용물을 기존 bangjangsan-plant-book 폴더에 덮어씁니다.
기존 .git 폴더는 유지하세요. node_modules 폴더는 압축에 포함되지 않습니다.
파일이 한 단계 더 중첩된 폴더에 들어가지 않게 합니다.

3. 설정 확인
이번 public-config.json에는 대화에서 확인한 Firebase 웹 공개 설정값과 아래 주소를 넣었습니다.
https://forest-plant-identify.plant-book.workers.dev/identify
Firebase 프로젝트는 plant-book-84803입니다.
이후 값을 바꾸었다면 백업한 자신의 설정을 사용하세요.
backend/wrangler.jsonc의 공개 Firebase 키도 같은 값으로 채워 두었습니다.
Pl@ntNet 비밀 키는 ZIP에 없으며 기존 Cloudflare Secret을 그대로 이용합니다.

4. 빌드와 Hosting 배포
Windows 명령 프롬프트에서 아래 명령을 한 줄씩 실행하세요.
cd /d "C:\Users\김준태\Documents\GitHub\bangjangsan-plant-book"
set "NODE_USE_SYSTEM_CA=1"
npm ci
npm test
npm run build
firebase deploy --only hosting --project plant-book-84803

이 UI 변경을 적용하는 데 Cloudflare 서버 재배포나 Firestore 규칙 재배포는 필요하지 않습니다.
v9의 Firestore 규칙을 아직 배포하지 않았다면 AI_SETUP.txt의 기존 규칙 배포 단계도 완료하세요.
firebase init으로 기존 설정을 덮어쓰지 마세요.
로그인 인증이 만료되었다면 이전에 사용한 Firebase 로그인 절차를 진행합니다.

5. 휴대폰에서 확인
Chrome 또는 Safari에서 https://plant-book-84803.web.app 을 열고 새로고침합니다.
1) 내 도감에서 로그인 / 기존 기록 확인.
2) 하단 사진 기록 → 사진 촬영과 앨범 선택 각각 확인.
3) 외부 사진 전송 동의 → AI 후보 분석 → 후보 선택.
4) 숲체원·식물 이름 입력, 메모와 GPS는 필요할 때만 입력.
5) 키보드를 열었을 때 입력란/저장 버튼까지 스크롤 가능한지 확인.
6) 내 도감과 사진 기록 사이를 오가도 작성한 사진·내용이 유지되는지 확인.
7) 비공개 저장 후 내 도감의 상세 사진·수정·삭제 확인.
8) 공유 도감에서 기관 선택·공유 신청과 담당자 검토 확인.
9) 기기 기록에서 이전 기록과 백업·복원이 보이는지 확인.

모바일 배치 기준: 320px부터 일반 휴대폰·태블릿 너비까지 유동 배치.
입력 글자 크기 16px, 주요 터치 영역 44px 이상, 하단 안전 영역 여백을 적용했습니다.
화면 확대를 막지 않습니다. 사진과 기관 로고의 원본 비율을 유지합니다.

주의할 화면 동작
내 도감과 사진 기록 사이에서는 입력을 유지합니다.
공유 도감/기기 기록으로 이동하거나 새로고침하면 저장하지 않은 작성 내용은 초기화됩니다.
기기 기록은 예전 브라우저 전용 저장이며 계정 기록으로 자동 전송하지 않습니다.
공식 로고는 현재 국립장성숲체원 표시입니다. 다른 기관 로고 자동 전환은 아직 없습니다.
AI 후보는 전문가 확정이 아니며 후보 점수는 검증된 정확도가 아닙니다.

검증 범위
기존 데이터/사진·위치 처리 단위 테스트 39개 및 프로덕션 빌드를 확인했습니다.
이 환경에서는 모바일 브라우저 시각 검사와 실물 휴대폰 카메라/GPS 검증을 하지 못했습니다.
위 5번의 실제 기기 점검이 필요합니다. 실제 배포와 실제 AI API 호출은 수행하지 않았습니다.
