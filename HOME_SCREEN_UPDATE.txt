새 기능

홈 화면 아이콘(192/512), 아이폰 터치 아이콘(180), 브라우저 탭 아이콘(32)을 준비했습니다.

Android/iPhone/iPad/일반 PC/앱 내 브라우저에 맞는 안내를 표시합니다.

이미지 처리

icon-frame.svg/share-frame.svg에 원본을 비율 유지로 배치하고 밝은 배경 위에 렌더링했습니다.
캐릭터와 글자를 다시 그리거나 잘라내지 않았습니다.
최종 아이콘 PNG는 불투명 배경이며 이미지 크기와 투명 여부를 확인했습니다.
생성된 PNG가 포함되므로 npm ci/build에 별도 이미지 편집 도구는 필요하지 않습니다.

홈 화면 기능 범위
앱 이름은 ㅇㄱㅁㅇ, 실행 주소는 사이트 첫 화면(/)입니다.
지원 브라우저에서 별도 앱 화면(standalone)으로 실행할 수 있게 설정했습니다.
브라우저에 따라 바로가기 형태로 열리거나 메뉴·설치 지원 여부가 다를 수 있습니다.
설치가 항상 자동 감지되거나 모든 환경에서 설치 버튼이 표시된다고 보장하지 않습니다.
실제로 홈 화면 모드로 실행한 경우에는 추가 안내 대신 실행 중 표시를 보여줍니다.

AI 분석, Firebase 로그인·계정 저장, 기관 목록·공유 조회는 인터넷 연결이 필요합니다.
이번에는 서비스 워커·오프라인 저장 큐·로그인/사진 응답 캐시를 추가하지 않았습니다.
홈 화면 추가가 곧 오프라인 사용 지원을 의미하지 않습니다.
브라우저와 홈 화면 앱의 로그인·기기 저장소는 환경에 따라 분리될 수 있습니다.
계정 도감은 같은 계정으로 다시 로그인해서 확인하세요.
