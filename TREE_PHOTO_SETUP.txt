v29 — 단풍나무·편백나무·갈참나무의 잎과 전체 모습

이번 수정본에는 보내주신 사진 6장이 이미 들어 있습니다.
처음 적용할 때 사진을 따로 추가하거나 Firebase에 업로드할 필요가 없습니다.
Firestore가 아닌 Firebase Hosting의 정적 파일로 배포합니다.
Spark 개발 구성과 기존 개인 기록의 사진 제한은 그대로입니다.

사진이 나오는 곳
- 숲 둘러보기의 각 나무 카드: 잎 → 전체 모습 순서
- 식물 찾기에서 해당 후보 선택 → 살펴보는 방법 보기
- 사진을 누르면 큰 사진을 새 창에서 열 수 있습니다.
- 사진은 참고용으로 표시합니다. v30에서는 사용자 제공 관찰 장소 설명을 별도로 연결했습니다. 지도 좌표·담당자 확인을 새로 등록한 것은 아닙니다. 장소 안내는 TREE_PLACE_SETUP.txt를 참고하세요.
- Pl@ntNet 후보의 비교 사진은 기존 제공 출처 사진을 계속 사용합니다.
- 내 도감에 이 사진을 개인 기록으로 자동 저장하거나 공유 신청하지 않습니다.

처음 적용하는 순서
1. 기존 프로젝트 폴더 전체를 백업합니다.
2. ZIP을 새 폴더에 풉니다.
3. 본인 public-config.json과 backend/wrangler.jsonc, .firebaserc(있을 때), .git,
   기존 src/experience-data.js와 직접 추가한 현장 자료를 보존합니다.
4. 새 public/experience 폴더와 src/experience-photos.js, src/TreePhotos.jsx를 적용합니다.
   기존 public 폴더 전체를 새 폴더 위에 덮어쓰면 새 사진이 빠질 수 있으니 직접 추가한 자료만 옮깁니다.
5. 새 프로젝트 폴더의 터미널에서 차례로 실행합니다.
   npm ci
   npm test
   npm run build
   firebase deploy --only hosting --project plant-book-84803
6. 앱을 새로 열어 사진과 크게 보기 링크를 확인합니다. 브라우저 저장 데이터는 지우지 마세요.

v24 여러 사진 공유 규칙·인덱스를 아직 배포하지 않았다면 Hosting 전에 실행합니다.
firebase deploy --only firestore --project plant-book-84803
Firebase init은 다시 실행하지 않습니다. Worker 재배포·설정 변경은 필요 없습니다.

편백나무 전체: hinoki-whole-v29.jpg
갈참나무 잎: galcham-oak-leaf-v29.jpg
갈참나무 전체: galcham-oak-whole-v29.jpg

단풍나무 전체: japanese-maple-whole-v29.jpg
파일명은 연결 오류를 줄이기 위해 영문으로 정리했습니다. 사진 내용은 원본 그대로입니다.

나중에 사진만 교체할 때
1. 교체할 사진을 PC에서 먼저 따로 백업합니다.
2. 위 목록에서 맞는 파일명을 찾아 새 사진의 이름을 똑같이 바꿉니다.
   예: 새 단풍나무 잎 사진 → japanese-maple-leaf-v29.jpg
   실제 JPEG 파일을 사용하세요. PNG/HEIC의 이름만 .jpg로 바꾸면 안 됩니다.
3. public/experience 폴더의 해당 파일을 교체합니다.
4. npm run build 후 Firebase Hosting을 배포합니다.
   dist 폴더를 직접 수정하면 다음 빌드에서 사라지니 public의 파일을 수정하세요.

사진 설명·촬영자 표시를 바꿀 때
기본 파일 연결은 src/experience-photos.js에 있습니다.
기본 표시는 잎 / 전체 모습, 출처는 제공 사진입니다.
촬영자나 기관명을 표시하려면 실제 출처를 확인해 credit 항목에 적을 수 있습니다.
기존 src/experience-data.js의 설명·장소·확인 여부는 이번에 바꾸지 않았습니다.

직접 등록한 사진이 이미 있다면
기존 photo에 사진이 있으면 그 사진을 우선 보여줍니다. 기존 자료를 강제로 덮어쓰지 않습니다.
이번 두 사진을 기본으로 사용하려면 해당 나무의 photo를 null로 두고 photos 항목은 생략합니다.
photos: []를 넣으면 기본 사진을 숨깁니다.
기관별로 다른 사진 두 장을 쓰려면 해당 나무에 아래처럼 photos를 추가합니다.
photos: [
  {src: '/experience/my-leaf.jpg', label: '잎', alt: '현장에서 찍은 잎', credit: '실제 촬영자 또는 기관명'},
  {src: '/experience/my-whole.jpg', label: '전체 모습', alt: '현장에서 찍은 나무 모습', credit: '실제 촬영자 또는 기관명'}
]
photos 배열이 있으면 photo와 기본 제공 사진보다 먼저 적용합니다.
이 예시 파일명은 사용법 예시입니다. 실제 파일을 public/experience에 넣어야 표시됩니다.

확인할 내용
각 나무 카드에 잎·전체 모습이 알맞게 연결됐는지 확인합니다.
모바일과 PC에서 사진이 잘리지 않고, 새 창으로 크게 열리는지 확인합니다.
사진이 없거나 읽히지 않아도 설명·메모 기능을 사용할 수 있습니다.
개인 기록의 여러 사진 저장·공유 기능과 이번 참고 사진은 서로 다른 기능입니다.
