전국 숲체원 식물 도감 — 1단계 데이터·공유 설계
작성일: 2026-10-12

이 파일 묶음은 다음 구현 단계에 사용할 설계입니다.
아직 로그인, 서버 저장, 실제 공유, AI 식별을 구현하거나 배포한 버전이 아닙니다.
기존 Spark 개발용 앱을 덮어쓰지 마세요. 기존 앱과 백업 파일을 계속 보관하세요.

파일 안내
1. DESIGN.txt: 한국어 설계. 먼저 이 파일을 읽으세요.
2. contracts.ts: 개발자가 구현할 데이터와 저장 인터페이스.
3. demo-data.json: 허구의 기관·사용자·식물 자료. 실제 기관 정보나 실제 식별 결과가 아닙니다.
4. ACCEPTANCE.txt: 다음 단계에서 실제로 시험할 조건.

GitHub에 보관하려면
현재 프로젝트 폴더에 docs\forest-design 폴더를 만든 뒤 이 묶음의 파일을 복사하세요.
GitHub Desktop에서 변경 내용을 확인하고 커밋·푸시하면 됩니다.
이 설계만 추가한 경우 npm 설치나 Firebase 배포는 필요하지 않습니다.
GitHub 브랜치를 사용한다면 forest-sharing 브랜치에서 작업하세요.

다음 구현 단계
실제 사용자 구분과 공용 기록 저장 → 사진 저장 → 공유 신청·담당자 검토·공개 조회
위 기능이 다른 두 기기에서 작동하는 것을 확인한 뒤 AI 식별을 연결합니다.
백엔드 제공자, 실제 계정 연결, 기관별 담당자 지정은 구현 단계에서 설정해야 합니다.

이전의 Spark 비용 선호는 유지합니다. 다만 이 설계는 특정 서비스의 무료 요금제를
확정하거나 청구를 변경한 것이 아니며, 사진 저장과 AI 서버의 비용 조건은 미정입니다.
