구현 완료 판정표 — 현재는 시험 계획이며 모두 미실행

A. 필수 시연
[ ] 다른 두 기기에서 사용자 A와 B로 로그인한다.
[ ] A가 촬영 또는 앨범 JPEG를 올리고 기관·장소를 선택하여 비공개 저장한다.
[ ] A는 재접속 후 사진을 볼 수 있다. B는 해당 개인 원본을 볼 수 없다.
[ ] A가 공개 범위를 확인하고 공유를 신청한다. B에게는 아직 보이지 않는다.
[ ] 해당 기관 담당자가 신청을 승인한다. B의 기관별 공개 목록에서 조회된다.
[ ] A가 공유를 철회한다. B가 새로 조회할 때 목록·사진 모두 접근할 수 없다.
[ ] 같은 식물 종을 두 번 관찰하면 종 수 1, 관찰 수 2로 표시된다.
[ ] 이름 모름 기록은 종 수에 포함하지 않으며 개인 기록에는 남는다.

B. 위치·권한
[ ] 앨범 사진을 선택해도 현재 GPS를 자동으로 촬영 장소로 쓰지 않는다.
[ ] GPS 거부·시간 초과 후 기관 선택과 수동 지정으로 저장 가능하다.
[ ] 공개 기본 위치가 기관 중심점이며 실제 관찰 좌표라고 표시하지 않는다.
[ ] 공개 응답과 사진 응답에 이메일, 소유자 ID, 비공개 좌표/저장소 경로가 없다.
[ ] 다른 사람의 원본 ID/사진 ID를 직접 요청해도 서버에서 거부한다.
[ ] 일반 사용자의 담당자 권한/검토 상태/공개 사본 직접 쓰기를 거부한다.
[ ] 기관 A 담당자가 기관 B 제출 및 공유하지 않은 개인 원본을 볼 수 없다.
[ ] 계정 전환 후 이전 사진·개인 기록·담당자 화면·늦은 응답이 남지 않는다.

C. 변경·오류·이전
[ ] 공개 후 수정 시 공개 접근이 종료되고 새 승인 전에는 재공개되지 않는다.
[ ] 공유 신청 후 수정하면 담당자가 오래된 제출을 승인할 수 없다.
[ ] 다른 기기 수정과 충돌하면 충돌을 안내하고 조용히 덮어쓰지 않는다.
[ ] 업로드/네트워크 실패 시 입력을 보존하고 재시도로 중복 기록을 만들지 않는다.
[ ] 삭제된 사진의 직접 새 요청을 거부한다. 고아 객체 정리는 실패 후 재시도한다.
[ ] 브라우저에서 처리한 사진과 서버 수신 사진을 검증하며 EXIF 제거를 확인한다.
[ ] 기존 v1 JSON 백업을 사전 검증하고 명시적 이전 선택 후에만 업로드한다.
[ ] 이전은 비공개로 진행하며 로컬 기록과 기존 백업을 삭제하지 않는다.
[ ] 일부 실패 시 기록별 상태가 표시되고 실패 항목만 안전하게 재시도할 수 있다.
[ ] 원래 생성 시각과 실제 관찰 시각을 혼동하지 않는다.

D. AI와 출품
[ ] 실제 식별 호출이 동작하고 실패 시 수동 입력/이름 모름으로 저장 가능하다.
[ ] AI 점수를 실제 검증 정확도라고 표시하지 않고 예시와 실제 응답을 구분한다.
[ ] 새 사진을 선택한 뒤 늦게 온 이전 AI 후보가 화면에 반영되지 않는다.
[ ] 식물 설명에 사용 가능한 출처가 있고 근거 없는 내용을 확정하지 않는다.
[ ] 제공자 교체 설정 위치와 키 입력 방법을 구동안내서에 적는다.
[ ] 비밀 키가 HTML, 클라이언트 번들, Git 저장소, 공개 로그에 없다.
[ ] 시연용 기관·식물·사진을 실제 전국 관찰 자료처럼 발표하지 않는다.
[ ] 안내서대로 새 환경에서 실행하고 실제 공유를 포함한 5분 이내 영상으로 검증한다.
