v25 — 식물 찾기 화면의 설명 줄이기

바로 보이는 내용
- 사진 선택 → 이름 찾기 → 내 도감에 남기기, 세 단계로 구성합니다.
- 로그인한 식물 찾기 화면에서 반복되는 캐릭터 소개 영역을 줄였습니다.
- 대표사진 전송 대상, 전송하지 않는 정보, AI 결과의 불확실성은 동의 앞에 표시합니다.
- 저장 버튼 앞에 나만 볼 수 있다는 안내와 공개 신청 경로를 표시합니다.
- 한글 이름이 없는 후보는 학명을 선택 버튼 안에 보여줍니다.

필요할 때 펼치는 내용
- 사진 잘 찍는 방법과 사진 크기 안내
- 사진 전송의 자세한 설명
- 후보의 학명·AI 점수·한글 이름 출처 (출처 링크 유지)
- 선택 항목인 메모·관찰 위치 (위도·경도 입력 포함)
- 관찰 안내의 글을 사진 기록에 넣으면 메모 영역이 자동으로 열립니다.

변경 범위
식물 찾기부터 저장까지의 문구와 배치 정리입니다.
전국 기관 선택, 숲 둘러보기, 사진 편집, 공유 선택·미리보기·검토 기능은 유지합니다.
사진 전송 동의는 기본 해제 상태를 유지합니다.
공개 범위·삭제 결과·오류·임시 기록 복구 안내는 임의로 숨기지 않습니다.
Firestore 규칙, 인덱스, 계정 저장 구조, Cloudflare Worker 변경은 없습니다.

휴대폰에서 확인할 것
1. 사진을 골랐을 때 촬영·분석·저장 버튼을 쉽게 찾는지 확인합니다.
2. 동의 전 사진 찾기 버튼이 비활성화되고, 동의 후 대표사진만 분석되는지 확인합니다.
3. 후보의 상세 내용을 펼쳐 학명·출처를 확인한 뒤 이름을 선택합니다.
4. 메모·위치를 펼쳐 입력하고 저장한 기록에서 다시 확인합니다.
5. 관찰 안내의 메모를 가져오면 입력란이 펼쳐지는지 확인합니다.
6. 화면 폭 360px 정도, 글자 확대, 키보드 열림 상태에서 가로 넘침과 버튼 가림을 확인합니다.
