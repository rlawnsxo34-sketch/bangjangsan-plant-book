v27 — 처음 방문한 사람을 위한 화면 간소화

첫 화면
- 어느 숲에 오셨나요? → 숲체원 선택 → 이 숲체원에서 시작하기 순서입니다.
- 처음 이용하시나요?를 펼치면 기능 소개와 저장 방법을 볼 수 있습니다.
- 기관 목록 새로고침, 기존 기록·백업, 선택 취소 기능은 유지합니다.

숲 둘러보기
- 나무 고르기는 관찰할 나무 목록으로 이동합니다.
- 사진으로 알아보기는 기존 식물 찾기 화면으로 이어집니다. 로그인이 필요합니다.
- 각 나무 카드는 이름·사진(등록된 경우)·관찰 질문·관찰 표시·메모란을 먼저 보여줍니다.
- 특징·관찰 요령 보기를 펼치면 자세한 설명과 관찰 힌트를 볼 수 있습니다.
- 학명·출처·담당자 확인 여부는 기존 자료 보기에서 확인합니다.
- 체험 소개·관찰 장소 안내를 펼치면 기존 소개와 장소 안내를 볼 수 있습니다.
- 사진이 없는 나무는 큰 빈칸 대신 사진 준비 중 문구를 작게 표시합니다.

계속 보이는 안내
관찰할 때 잎·가지를 꺾지 않는 등의 주의사항, 시범 체험 확인 표시,
글의 자동 저장 여부를 알려줍니다. 새로고침·종료·기관/계정 변경 시
메모가 지워질 수 있으므로 내 기록 보기에서 먼저 파일로 받으세요.
글이 있는 상태에서 사진 찾기로 이동할 때 로그인에 따른 삭제 안내도 유지합니다.

기록의 의미
나무를 살펴봤다는 표시는 사용자가 직접 체크하는 표시입니다.
식물 이름의 확정, 현장 방문 인증, 전체 식물의 완성률을 뜻하지 않습니다.
실제 관찰 장소와 식물 사진을 새로 확인하거나 추가한 버전은 아닙니다.
기관별 현장 자료는 기존 src/experience-data.js를 보존해서 사용하세요.

적용
기존 프로젝트를 백업하고 START_HERE.txt 순서로 본인 설정·현장 자료를 옮깁니다.
npm ci → npm test → npm run build 후 Hosting을 배포합니다.
firebase deploy --only hosting --project plant-book-84803
v24의 여러 사진 공유 규칙·인덱스를 아직 배포하지 않았다면 Hosting보다 먼저 배포하세요.
firebase deploy --only firestore --project plant-book-84803
Firebase init은 다시 실행하지 않습니다. Worker 설정·재배포도 필요 없습니다.

휴대폰 확인
1. 시작 화면에서 소개를 열지 않고 숲체원을 선택할 수 있는지 확인합니다.
2. 나무 고르기로 목록에 이동하고 관찰 질문이 먼저 보이는지 확인합니다.
3. 특징·관찰 요령을 펼쳐 내용을 확인합니다.
4. 메모 한 줄을 적고 내 기록 보기에서 이미지 카드 또는 글 파일을 받습니다.
5. 글을 적은 뒤 사진으로 알아보기로 이동할 때 삭제 안내가 보이는지 확인합니다.
6. 작은 화면·큰 글자·키보드 열린 상태에서 가로 넘침과 버튼 가림을 확인합니다.
