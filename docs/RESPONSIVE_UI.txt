v28 — 모바일·태블릿·PC 화면 구성

같은 주소에 접속해도 화면 폭에 맞춰 배치가 자동으로 달라집니다.
기기 이름 대신 브라우저 안의 사용 가능한 폭을 기준으로 하므로,
PC에서도 창을 좁히거나 확대하면 모바일 배치로 전환될 수 있습니다.
별도의 모바일 사이트나 PC 사이트를 배포할 필요가 없습니다.

모바일 (폭 768px 미만)
- 네 메뉴를 화면 아래에 고정합니다.
- 사진 선택 → 이름 찾기 → 내 도감에 남기기를 세로로 진행합니다.
- 나무 카드와 공유 신청도 한 열로 보여줍니다.
- 작은 화면에서는 상단의 보조 배지를 숨기고 주요 로고를 유지합니다.
- 버튼 크기와 입력창 16px 글자, 하단 안전 여백, 확대 기능을 유지합니다.

태블릿 (폭 768~1023px)
- 하단 메뉴를 유지하며 화면 폭을 넓힙니다.
- 나무 카드·도감 목록은 두 열로 보여줍니다.
- 사진 찾기 입력과 공유 신청은 세로 흐름을 유지합니다.

PC (폭 1024px 이상)
- 메뉴를 상단에 고정합니다. 키보드로도 메뉴 다음에 본문으로 이동합니다.
- 전체 화면은 최대 1280px까지 활용합니다.
- 식물 찾기는 왼쪽 사진, 오른쪽 분석·기록 입력으로 나눕니다.
- 앨범 선택 버튼은 사진 파일 선택으로 표시합니다.
- 숲 둘러보기는 두 열, 폭 1200px 이상에서는 세 나무를 나란히 배치합니다.
- 내 도감의 이름 묶음·기록 목록을 두 열로 배치합니다.
- 함께 보기는 왼쪽 공개 기록, 오른쪽 내 공유 신청·상태로 나눕니다.
- 사진 편집·기록 상세·공개 검토 창은 최대 860px까지 넓힙니다.
- 로그인과 처음 숲체원 선택 화면은 읽기 편한 폭을 유지합니다.

동작
화면 크기에 따른 별도의 계정이나 저장소는 만들지 않습니다.
같은 입력창과 상태를 사용하며 CSS로 배치만 바꿉니다.
전환 때문에 사진을 다시 분석하거나 임시 기록을 새로 불러오지 않습니다.
공유 사진 선택·미리보기·명시적 동의, 위치 접근 동의와 접근 규칙은 유지합니다.
PC의 사진 촬영 버튼 동작은 브라우저와 카메라 지원에 따라 다를 수 있습니다.
사진 파일 선택을 이용하면 PC에 저장된 사진을 추가할 수 있습니다.

적용
기존 폴더를 백업하고 START_HERE.txt에 따라 본인 설정·현장 자료를 보존합니다.
npm ci
npm test
npm run build
firebase deploy --only hosting --project plant-book-84803
v24의 공유 규칙·인덱스를 아직 배포하지 않았다면 Hosting보다 먼저:
firebase deploy --only firestore --project plant-book-84803
Firebase init, Worker 재배포, 요금제 변경은 필요 없습니다.

배포 후 확인
1. 휴대폰에서 하단 네 메뉴가 보이고 마지막 버튼을 가리지 않는지 확인합니다.
2. PC에서 상단 네 메뉴와 사진·분석의 두 열 배치를 확인합니다.
3. PC에서 사진·이름·메모를 입력한 채 창을 좁혔다 넓힙니다. 내용이 남는지 확인합니다.
4. 사진 후보 선택·저장·사진 편집·공유 신청과 취소를 두 환경에서 확인합니다.
5. 공유 미리보기에는 고른 사진만 보이고, 동의 전 신청 버튼이 비활성화되는지 확인합니다.
6. 작은 휴대폰, 태블릿 가로·세로, PC 확대 200%, 긴 식물 이름을 점검합니다.
7. 키보드 Tab/Shift+Tab으로 메뉴·입력·버튼 순서를 확인합니다.
8. 상세 창 안에서 초점 이동, Escape/닫기, 닫은 뒤 원래 버튼으로 돌아오는지 확인합니다.

이 환경에서는 기능 검사와 빌드를 수행했습니다. 해상도별 실제 브라우저 렌더링과
휴대폰 카메라·터치 키보드 검사는 별도로 필요합니다.
