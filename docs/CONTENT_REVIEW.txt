v44 문구·설명 점검

지도
- 장소를 먼저 고르는 흐름에서 사진으로 나무를 먼저 고르는 흐름으로 변경.
- 기본 안내: 사진에서 나무를 고르면, 찾아갈 장소를 보여드려요.
- 개별 지도 위치가 아직 등록되지 않았어요 → 지도 위치가 아직 없어요.
- 같은 장소의 대표 위치 안내는 실제 기준 나무를 짧게 표시.
- 긴 지도 의미 설명과 담당자 안내는 펼쳐 보기 안에 배치.
- 장소 목록은 필요할 때 펼쳐 보도록 변경.

내 도감
- AI가 구분한 이름 → AI에서 고른 이름. 정답 확인으로 오해하지 않게 변경.
- 직접 적은 기록 등 기록 → 직접 입력·기타 기록.
- 학명 기준 집계 설명은 이름을 모아 보여주는 기준을 펼쳐 확인.
- 직접 입력·기타의 설명은 해당 항목을 골랐을 때만 표시.

숲 둘러보기
- 지도 화면에서 중복되는 소개 한 줄 제거.
- 이 화면에 등록된 정보에는 담당자의 최종 확인 표시가 아직 없어요
  → 담당자가 아직 최종 확인하지 않은 안내예요.

유지한 필수 안내
사진 전송 동의, AI 이름의 불확실성, 공개 여부, 방문 기록 소멸 조건,
장소 좌표와 개별 나무 위치의 차이, 실제 저장 버튼은 숨기거나 없애지 않았습니다.
사용자가 직접 작성한 식물 설명·장소·메모는 바꾸지 않았습니다.
