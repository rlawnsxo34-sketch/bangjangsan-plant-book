v49 화면 변경

연결
- 식물 찾기·내 도감: 공개 나무 지도를 열고 원래 화면으로 돌아오기.
- 작성 폼·내 도감 필터를 지우지 않고 화면만 가림.
- 계정·기관 변경 때 기존 초기화와 접근 규칙 유지.
- 동일 숲체원의 기록 상세에 지도 연결. 다른 기관으로 임의 이동하지 않음.
- 개인 촬영 좌표를 공개 위치로 사용하지 않음.

간결함
- 다른 이름과 설명 자료 보기와 체험 주소 나누기를 제거.
- 실제 공유 신청·공개 목록은 함께 보기에 유지.
- 식물 원본 데이터의 학명·출처와 사진 이용 조건은 보존.

스타일
- 짙은 초록, 밝은 바탕, 연한 테두리와 절제된 그림자로 통일.
- 모바일은 하단 4개 메뉴, PC는 위쪽 4개 메뉴 유지.
- 작은 화면의 시작 버튼은 아이콘 옆에 제목·설명을 놓아 과도한 줄바꿈을 줄임.
- 한글 단어 우선 줄바꿈, 제목은 균형 있게 줄바꿈.
- 긴 주소·학명은 화면 안에서 줄을 바꾸도록 예외 처리.
- 초점 표시·최소 터치 영역·동작 줄이기 설정 유지.

확인
로컬 미리보기의 모의 데이터로 PC·모바일 320/390px 화면을 확인했습니다.
실제 Firebase 계정이나 사진은 브라우저 미리보기에 쓰지 않았습니다.
실제 기기와 카카오 SDK 운영 연결은 배포 후 확인해야 합니다.
