v26 — 함께 보기와 공유 신청 화면 간소화

이용 순서
1. 함께 보기 → 내 기록 함께 나누기에서 기록을 고릅니다.
2. 공개할 사진 1~3장만 체크하고 함께 보여줄 글을 씁니다. 글은 선택사항입니다.
3. 공개 전 확인하기를 누릅니다.
4. 선택한 사진과 식물 이름·숲체원·글을 확인합니다.
5. 동의한 뒤 공유 신청하기를 누릅니다. 담당자가 확인하기 전에는 공개되지 않습니다.

화면 변경
- 사진과 글 고르기 / 공개 전 확인, 두 단계로 나누었습니다.
- 미리보기에는 선택하지 않은 개인 사진과 편집 입력란을 표시하지 않습니다.
- 사진·글 다시 고르기로 돌아가면 사진 선택과 글은 유지하며, 다음 확인에서는 다시 동의해야 합니다.
- 다시 신청·취소에 관한 설명은 필요할 때 펼쳐봅니다.
- 개인정보 제외, 얼굴·연락처·민감한 장소 확인, 사본 회수의 한계는 동의 앞에 그대로 표시합니다.
- 공유 취소 확인창의 돌아가기 버튼으로 실제 취소와 구분합니다.
- 처리 중에는 신청 중…으로 표시합니다.

동작 유지
사진과 동의는 자동 선택하지 않습니다. 고른 사진만 신청·공개합니다.
개인 메모·이메일·정확한 위치를 신청 사본에 넣지 않습니다.
기존 승인·보류·취소, 오류 후 같은 요청 재확인, 계정 전환 시 초기화는 유지합니다.
승인은 공개할 사진·글의 적합성을 확인하는 절차이며 식물 이름의 확정은 아닙니다.
규칙·인덱스·Firebase/Cloudflare 설정·현장 자료·로고·식물 찾기 화면은 이번에 변경하지 않았습니다.

적용
기존 폴더를 백업하고 본인 설정·현장 자료를 보존하세요.
npm ci → npm test → npm run build 순서로 실행합니다.
v24의 규칙·인덱스를 이미 배포했다면:
firebase deploy --only hosting --project plant-book-84803
아직 v24 규칙을 배포하지 않았다면 Hosting 배포 전에:
firebase deploy --only firestore --project plant-book-84803
Firebase init은 다시 실행하지 않습니다. Worker 재배포도 필요 없습니다.

휴대폰 확인
- 3장 중 2장 선택 → 공개 전 확인에는 2장만 나오는지 확인합니다.
- 다시 고르기 → 사진 선택·글 유지 → 재확인 시 동의 해제를 확인합니다.
- 신청 후 내 공유 신청 상태에서 결과를 확인합니다.
- 담당자 계정 승인 후 로그인하지 않은 화면에서 선택한 사진만 나오는지 확인합니다.
- 공유 취소창의 돌아가기는 유지, 공유 취소 확인은 실제 공개 철회인지 확인합니다.
- 작은 화면·큰 글자·키보드 열린 상태에서 가로 넘침과 버튼 가림을 확인합니다.
