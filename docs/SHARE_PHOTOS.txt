사진을 골라 함께 나누기 — v26 화면 기준

작성자 이용 순서
1. 식물 찾기에서 사진과 글을 내 도감에 저장합니다. 한 기록에 최대 3장을 넣을 수 있습니다.
2. 함께 보기 → 내 기록 함께 나누기에서 공유할 개인 기록을 고릅니다.
3. 공개할 사진에만 표시합니다. 대표사진도 자동 선택하지 않습니다. 추가사진만 골라도 됩니다.
4. 함께 보여줄 글을 직접 씁니다. 개인 메모는 자동으로 옮기지 않습니다.
5. 공개 전 확인하기를 누르고 사진 수·사진 내용·식물 이름·숲체원·공개 글을 확인합니다.
6. 미리보기의 사진과 글을 공개하는 데 동의하고 공유 신청하기를 누릅니다.
7. 내 공유 신청 상태에서 결과를 확인합니다. 승인 전에는 일반 방문객에게 공개되지 않습니다.

선택과 미리보기
공유로 고른 사진 1~3장만 미리보기에 나옵니다. 고르지 않은 사진은 검토 사본과 공개 사본에 넣지 않습니다.
대표사진을 바꾸는 기능과 공개할 사진을 고르는 기능은 별개입니다. 여기에서 선택해도 내 도감의 대표사진 순서는 바뀌지 않습니다.
사진·글 다시 고르기를 누르면 동의를 해제합니다. 새 미리보기를 확인하고 다시 동의해야 합니다.
사진 다시 불러오기는 최신 기록을 읽고 사진 선택·미리보기·동의를 초기화합니다.
원본이 다른 기기에서 수정되었거나 기관 정보가 달라졌으면 오래된 미리보기로 제출하지 않습니다.
공유 초안은 이 화면에서만 준비합니다. 계정/기관 전환이나 화면 종료 시 지워지므로 필요한 공개 글은 따로 보관하세요.

담당자 확인
함께 보기 → 숲체원 담당자 확인 → 검토하기에서 신청자가 선택한 사진을 모두 봅니다.
선택한 사진과 공개 글의 적합성을 확인한 뒤 승인/보류와 사유를 저장합니다.
담당자는 선택하지 않은 개인 원본이나 개인 메모·정확한 관찰 좌표를 볼 수 없습니다.
검토 중 신청이 바뀌거나 원본이 수정되었으면 옛 화면에서 승인하지 않습니다. 목록을 다시 불러와 확인하세요.
승인은 공개 적합성 검토이며, 식물 종 확정을 의미하지 않습니다.
이전 앱은 여러 사진 중 첫 사진만 보여줄 수 있습니다. 여러 사진 검토에는 업데이트한 앱을 사용하세요. 새 규칙은 사진 일부를 빠뜨리거나 사진을 더 넣는 승인 사본을 거부합니다.

일반 방문객
로그인하지 않아도 함께 보기에서 승인된 기록을 열고 공유로 선택한 사진 전체와 공개 글을 볼 수 있습니다.
기존 한 장짜리 공개 기록과 대기 신청도 계속 열 수 있습니다. 기존 기록을 자동으로 여러 사진 공개로 바꾸지는 않습니다.

취소·수정·재요청
공유 취소는 공개 사본 전체를 삭제하고 개인 원본은 유지합니다.
내 도감에서 이름·글·사진 등을 수정하면 기존 신청과 공개를 철회합니다. 수정 후 사진을 다시 골라 신청해주세요.
기존 승인 기록에 새로 신청하면 기존 공개는 내려가고 새 신청이 검토 대기로 바뀝니다.
이미 검토 대기 중인 내용을 바꾸려면 기존 신청부터 취소하세요.
통신 오류 뒤 같은 미리보기로 다시 요청하면 같은 요청 ID로 확인합니다. 이미 승인·보류·취소된 같은 요청을 재시도로 다시 검토 대기로 돌리지 않습니다. 이미 처리되었다고 나오면 내 공유 신청 상태를 확인하세요.
이미 다른 사람이 받은 이미지와 캡처, 열어둔 화면의 사본까지 회수할 수는 없습니다.

데이터와 배포
개인 사진의 원본과 소유권 구조는 유지합니다. 각 사진은 기존 압축·용량 제한을 그대로 따릅니다.
새 신청은 selectedPhotoIndexes와 내부 submissionId를 기록하고, 선택한 사진만 imageData와 optional additionalImages로 복사합니다.
공개 문서에는 선택한 사진과 기존 공개 필드만 넣으며 내부 요청 ID·개인 원본 번호·이메일·개인 메모·정확한 관찰 위치는 넣지 않습니다.
규칙은 선택 번호의 수·범위·중복·순서와 실제 소유한 사진 바이트를 확인합니다. 담당자는 신청 사본과 다른 사진 구성을 공개할 수 없습니다.
요청·공개 문서의 additionalImages는 인덱스에서 제외합니다. 새 Storage·Cloud Functions·Worker API나 요금제 변경은 필요하지 않습니다.
v24 규칙과 인덱스를 이미 배포했다면 v26은 Hosting만 배포합니다. 아직 적용하지 않았다면 규칙·인덱스를 먼저 배포하세요. START_HERE.txt를 따르세요.

배포 후 역할별 확인
작성자: 3장 중 2장만 선택 → 미리보기에는 2장만 보임 → 동의 후 신청.
담당자: 선택한 2장과 공개 글을 확인 → 승인.
방문객: 로그인 없이 승인된 2장만 열림. 선택하지 않은 사진은 보이지 않음.
작성자: 공유 취소 → 공개 목록에서 빠짐 → 내 도감의 원본 3장은 유지.
작성자: 사진 수정 → 기존 공유 철회 → 새 사진을 골라 재신청.
담당자: 오래된 검토 화면으로 승인 시도 → 최신 신청 확인 안내.
실제 휴대폰 촬영·표시·다운로드·네트워크 장애와 외부 배포/방문객 시험은 별도로 확인해야 합니다.
