사진 검색에서 나무 살펴보기 — v21

1. 바뀐 나무
시범 관찰 대상은 편백나무, 갈참나무, 단풍나무입니다.
갈참나무의 학명은 Quercus aliena이며, 굴참나무 Quercus variabilis와 다른 종입니다.
갈참나무는 잎의 톱니 모양과 앞뒤 색을 비교하는 질문으로 바꿨습니다.
설명 출처: BRIS 어린이생물도감 · 국립수목원 제공
https://www.bris.go.kr/portal/book/childIlustbkDetailPopup.do?ilustbkNo=102&menuId=114
사진·현장 위치·담당자 확인 표시는 비어 있습니다. 실제 나무를 확인한 뒤 추가하세요.
굴참나무의 기존 사진과 장소를 이름만 바꾸어 갈참나무에 붙이지 마세요.
기존 계정 도감/기기 기록과 이미 받은 파일은 수정하지 않습니다.
일반 식물 검색에서는 굴참나무도 계속 원래 이름으로 표시합니다.

2. 이용 순서
기관 선택 → 식물 찾기에서 로그인 → 사진 촬영/선택 → 동의 후 분석 → 후보 이름 선택.
편백나무·갈참나무·단풍나무를 선택하면 ‘살펴보는 방법 보기’가 나타납니다.
사진 화면 안에서 설명·질문을 읽고 메모하므로 사진을 다시 고를 필요가 없습니다.
설명만 읽는 것으로 살펴봤다는 표시가 켜지지 않습니다. 직접 확인한 경우에만 표시하세요.
특징 메모는 숲 둘러보기의 같은 나무 메모와 연결됩니다.
‘이 글을 사진 기록에 넣기’를 누르면 사진 기록의 글 칸에 들어갑니다. 이미 다른 글이 있으면 바꿀지 묻습니다.
마지막으로 ‘내 도감에 저장하기’를 눌러야 계정에 저장됩니다. 버튼을 누르기 전에는 저장 완료가 아닙니다.
숲 둘러보기에서 내 기록 보기로 가면 같은 메모를 글 파일이나 이미지로 받을 수 있습니다.
로그인 없이 먼저 숲 둘러보기를 이용해도 됩니다. 로그인/계정 전환 때 메모는 지워지니 먼저 파일로 받으세요.

3. 보관과 다른 식물
관찰 메모 자체는 페이지 메모리에서만 유지됩니다. 새로고침·종료·기관 변경·계정 변경 시 지워집니다.
사진 기록의 글 칸으로 옮긴 내용은 기존 사진 기록의 임시 보관 정책을 따릅니다. 계정 저장 전까지 다른 기기로 옮겨지지 않습니다.
다른 후보를 고르면 열린 안내를 접습니다. 해당 나무의 기존 관찰 메모는 같은 기관에서 다시 고르면 볼 수 있습니다.
이름을 직접 바꾸면 AI 선택 정보가 해제되고 연결 안내도 사라집니다.
다른 식물은 안내 준비 중으로 표시하고, 기존 사진·이름·글 저장 기능을 계속 제공합니다.
한국어 이름의 일부가 같다는 이유로 연결하지 않습니다. 선택한 학명이 등록된 종과 일치할 때만 연결합니다.
실제 방문, 정확한 위치, 식물 이름의 확정이나 관찰 완료를 자동으로 판단하지 않습니다.
추가 분석 호출·Firebase 컬렉션·요금제 변경 없이 동작합니다.

4. 배포 후 확인
- 실제 사진 분석 후 세 종류를 골랐을 때 안내가 나타나는지.
- 안내를 열고 닫아도 사진이 남는지.
- 글을 옮기기 전에는 사진 기록의 글 칸이 바뀌지 않는지.
- 기존 글 교체를 취소하면 그대로 남는지.
- 저장 후 같은 계정으로 다른 기기에서 해당 사진 기록과 글이 보이는지.
- 숲 둘러보기로 이동하면 같은 메모가 보이는지.
- 기관/계정 변경 후 이전 메모가 보이지 않는지.
- 다른 참나무 후보에 갈참나무 안내가 나타나지 않는지.
현장 방문객 시험은 추가 수정이 끝난 뒤 진행합니다.
