이번 변경
1. 후보 카드는 한글 이름을 크게, 학명과 후보 점수를 아래에 표시합니다.
2. 출처를 확인한 초기 20종은 학명이 정확히 일치할 때 한글 이름을 연결합니다.
3. 초기 자료에 없는 종은 Pl@ntNet에서 받은 한국어 일반 이름이 있으면 표시합니다.
4. 한글 이름을 확인하지 못하면 '한글 이름 미등록'과 학명을 표시합니다.
5. 후보 선택 시 입력란에는 한글 이름이 있으면 한글 이름, 없으면 학명이 들어갑니다.
   사용자가 직접 수정할 수 있고, 학명은 선택한 AI 후보 정보로 유지됩니다.
6. 기존 저장 기록의 이름을 자동 변경하지 않습니다.

한국어 요청 방식
Cloudflare 서버가 Pl@ntNet /v2/languages를 조회합니다.
ko가 실제 지원 목록에 있으면 lang=ko로 식별을 요청합니다.
ko가 없거나 언어 목록을 확인하지 못하면 lang=en으로 요청합니다.
정상 언어 목록 확인은 24시간 캐시, 실패는 10분 뒤 재확인 대상으로 둡니다.
언어 확인 요청은 식별 요청과 별도입니다. 식별 실패를 자동 재호출하지 않습니다.
기존 호출 한도와 요청 중복 방지는 유지합니다.
개발 과정에서 실제 비밀 키로 한국어 응답 지원 범위를 확인하지는 않았습니다.

초기 이름 목록의 범위와 출처
전체 한국 식물 목록이 아닙니다. 현재 출처 대조 20종만 포함합니다.
출처: 국립생물자원관, 한반도 알레르기 유발 꽃가루 가이드북 (2015).
https://www.nibr.go.kr/aiibook/catImage/103/Allergenic%20pollen%20in%20Korea.pdf
학명·국명 사실 관계만 확인하여 사용했고 본문과 사진은 배포하지 않습니다.
backend/korean-names.mjs에 각 학명, 한글 이름, 해당 페이지가 있습니다.
학명의 이명/변종/교잡종을 추측해 비슷한 종으로 연결하지 않습니다.
이름 연결은 종 동정의 검증이나 최신 국가표준식물목록 전체 동기화를 뜻하지 않습니다.
Pl@ntNet 한국어 일반 이름도 공식 표준 국명으로 확정했다고 표시하지 않습니다.
