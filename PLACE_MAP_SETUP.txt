v32 안내: 숫자 입력 대신 TREE_MAP_SETUP.txt의 지도 선택 방식을 기본으로 사용합니다. 아래 v31 방법은 소스 좌표를 직접 다루는 보조 안내입니다.

v31 — 실제 나무 좌표를 확인하고 지도에 연결하기

현재 상태
편백나무·갈참나무: 숙소동1 부근 난간 근처
단풍나무: 숙소동2에서 숲누림길로 올라가는 시작점
장소 설명과 사진은 유지했습니다. 세 나무의 좌표는 아직 모두 비어 있습니다.
숲체원 대표 좌표나 숙소동 중앙을 나무 좌표로 대신 넣지 않았습니다.
정확한 좌표를 넣으면 어디서 볼 수 있나요?에 지도에서 보기 (카카오맵) 링크가 나옵니다.

1. 현장에서 좌표 확인하기 (기존 앱 이용)
- 휴대폰으로 실제 나무를 관찰할 수 있는 안전한 장소에 섭니다.
- 배포한 앱에서 장성숲체원 선택 → 식물 찾기 → 로그인합니다.
- 내 도감에 남기기 아래 메모·위치 추가하기를 펼칩니다.
- 현재 위치 확인하기를 누르고 브라우저 위치 접근을 허용합니다.
- 선택한 위치(위도·경도)에 나오는 두 숫자를 메모합니다.
- 먼저 나오는 숫자가 위도(lat), 뒤 숫자가 경도(lng)입니다.
- 좌표 확인을 위해 사진이나 개인 기록을 저장할 필요는 없습니다.
- 편백나무와 갈참나무가 같은 구역이라도 각각 위치를 확인해주세요.
- 집이나 사무실에서 현재 위치를 누르면 나무의 위치가 나오지 않습니다.
- 숲에서는 GPS 오차가 있을 수 있으니 현장 위치와 지도를 비교해 확인합니다.

기록해서 전달할 형식
편백나무: 위도 ___ / 경도 ___
갈참나무: 위도 ___ / 경도 ___
단풍나무: 위도 ___ / 경도 ___
좌표를 보내주시면 해당 나무에 연결한 수정본을 만들 수 있습니다.

2. 직접 입력하려면
- 기존 프로젝트 폴더 전체를 백업합니다.
- src/observation-places.js를 엽니다.
- OBSERVATION_PLACES 안 jangseong 키가 실제 forestCenters 문서 ID와 같은지 확인합니다.
  이미 다른 기관 ID를 쓰고 있다면 문서 ID를 바꾸지 말고 이 파일의 키를 맞춥니다.
- hinoki는 편백나무, galcham-oak는 갈참나무, japanese-maple은 단풍나무입니다.
- 각 나무의 coordinates: null을 아래처럼 바꿉니다.
  coordinates: {lat: null, lng: null}
- lat 뒤의 null을 실제 위도 숫자로, lng 뒤의 null을 실제 경도 숫자로 바꿉니다.
  숫자에 따옴표를 붙이지 않습니다. 둘 중 하나라도 비어 있으면 링크는 나오지 않습니다.
- label은 장소 설명이니 그대로 유지해도 됩니다.
- 기존 v30 파일에서 기관 ID나 장소를 수정했다면 해당 설정 값만 새 파일로 옮깁니다.
  새 좌표 검증·지도 연결 함수가 있으므로 예전 파일 전체로 덮어쓰지 마세요.

3. 적용과 배포
START_HERE.txt대로 설정·현장 자료를 보존하고 차례로 실행합니다.
npm ci
npm test
npm run build
firebase deploy --only hosting --project plant-book-84803
v24의 여러 사진 공유 규칙·인덱스를 아직 배포하지 않았다면 Hosting보다 먼저:
firebase deploy --only firestore --project plant-book-84803
Firebase init, Worker 재배포, 추가 지도 키 설정은 필요 없습니다.

4. 실제 지점 확인
- 장성숲체원 → 숲 둘러보기 → 해당 나무 → 지도에서 보기 (카카오맵)를 누릅니다.
- 새 창의 지점이 실제 관찰 장소인지 확인합니다. 숫자 범위 검사만으로 실제 위치가 맞는지는 알 수 없습니다.
- 모바일에서는 기기 설정에 따라 외부 지도 앱이나 웹페이지가 열릴 수 있습니다.
- 다른 기관에서 장성의 좌표 링크가 나오지 않는지 확인합니다.
- 위도·경도 하나가 비거나 형식이 틀리면 지도 링크 없이 장소 설명을 유지합니다.

개인 기록과의 관계
여기에 입력한 좌표는 모든 이용자에게 안내할 공개 관찰 지점입니다.
방문객의 개인 GPS 기록이나 사진의 촬영 정보를 자동으로 가져오지 않습니다.
화면을 열기만 했을 때 지도 서비스에 좌표를 요청하지 않습니다.
이용자가 지도 링크를 누르면 등록한 공개 장소 이름·좌표로 카카오맵을 엽니다.
로그인 정보·개인 메모·개인 좌표는 링크에 넣지 않습니다.
이 기능은 공개 관찰 지점 보기입니다. 방문객 발견 구역을 모으는 지도는 후속 단계입니다.
