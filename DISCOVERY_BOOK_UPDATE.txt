작성일: 2026-10-16

이번 화면
내 도감에서 관찰 기록 건수, 서로 다른 선택 AI 후보 수, 후보 미분류 기록 건수를 보여줍니다.
목표 종 목록, 달성률 %, 완료/미완료 판정은 만들지 않습니다.
계속 발견하고 저장하는 방식의 도감입니다.

식물 후보별 보기
선택한 AI 후보의 학명(scientificName)을 기준으로 기록을 묶습니다.
같은 후보를 여러 번 저장하면 하나의 후보 아래에 여러 관찰 기록이 나타납니다.
한 후보를 펼치면 처음/최근 저장일, 기록된 숲체원 이름, 개별 기록을 확인할 수 있습니다.
개별 기록을 누르면 기존 상세 화면에서 내 사진과 메모를 보고 수정/삭제합니다.
다른 기관에서 같은 학명을 선택한 기록도 내 개인 도감에서는 함께 묶습니다.
기관별 공유·담당자 검토는 기존처럼 기관을 구분합니다.

집계의 의미
AI 후보 수는 확정된 식물 종 수가 아닙니다. 사용자 선택 기록의 묶음 수입니다.
학명의 앞뒤 공백과 연속 공백만 정리하고, 이명·변종·교잡종을 추측해 합치지 않습니다.
사용자가 같은 한글 이름을 직접 입력했다고 같은 식물로 판단하지 않습니다.
AI 후보 정보가 없는 기록은 후보 미분류로 표시하고 개별 기록으로 유지합니다.
미분류 기록은 직접 입력한 기록, AI 후보를 선택하지 않은 기록, 후보 정보가 지워진 이전 기록 등을 포함합니다.
기존 데이터에 후보 정보가 없으면 임의로 채워 넣지 않습니다.

최근 새로 모은 후보와 날짜
각 후보의 현재 남아 있는 기록 중 가장 이른 저장일로 최근 후보 목록을 만듭니다.
같은 후보를 다시 관찰했다고 새 후보로 집계하지 않습니다.
첫 기록을 삭제하면 남아 있는 기록 기준으로 첫 저장일과 최근 목록이 달라질 수 있습니다.
표시 날짜는 저장일이며 촬영일/실제 관찰일로 추정하지 않습니다.

집계 범위
계정 도감에 불러온 기록만 계산하며, 기기 도감·다른 사람의 공개 기록은 포함하지 않습니다.
기존 개발용 계정 저장 한도와 최신 기록 조회 한도는 유지합니다.
최신 51건이 표시되는 경우 전체 기록이 아닐 수 있어 집계 범위 안내를 표시합니다.
전체 기록을 무제한으로 읽거나 새 통계 문서를 만들지 않습니다.

기록 목록과 검색
'기록 목록'에서 개별 기록을 시간 순으로 볼 수 있습니다(서버의 기존 정렬 기준).
이름·학명·숲체원으로 찾을 수 있습니다. 예: 소나무, Pinus, 장성.
검색 시 조건에 맞는 기록만 후보별/목록으로 표시합니다.
상단 집계와 최근 후보는 검색 전 불러온 기록 전체 기준입니다.
검색된 후보 묶음의 날짜는 현재 검색 결과에 포함된 기록 기준입니다.

수정 시 AI 후보 정보
메모나 관찰 기관만 수정하면 선택한 후보 정보를 유지합니다.
식물 이름을 다른 이름으로 수정하면 기존 AI 후보 정보를 제거하고 미분류로 표시합니다.
과거 버전에서 이미 제거된 후보 정보는 자동 복원하지 않습니다.
기관이나 내용을 수정하면 기존 공개 공유를 철회하는 동작은 그대로 유지됩니다.
이름이 바뀌어 후보에서 빠지거나 기록을 삭제하면 집계는 남아 있는 기록 기준으로 다시 계산됩니다.

적용 순서
1. 기존 프로젝트와 public-config.json을 백업합니다.
2. ZIP을 별도 폴더에 풀고 내용물을 기존 프로젝트 폴더에 적용합니다.
   .git은 유지하고, 폴더가 중첩되지 않게 합니다.

   이전 이후 값을 변경했다면 자신의 백업 설정을 유지합니다.
4. v13 기관 ID 저장 규칙을 이미 배포했다면 아래 명령만 실행합니다.

휴대폰에서 확인
1. 기관 선택 → 로그인 → 내 도감.
2. 기존 기록 건수와 선택 AI 후보 수, 미분류 기록 건수 확인.
3. 같은 학명의 후보를 두 번 저장하면 후보 수는 같고 기록 수만 늘어나는지 확인.
4. 동일한 이름을 직접 입력한 기록 두 건은 미분류로 따로 남는지 확인.
5. 후보를 펼치고 기관·저장일·사진·메모 확인.
6. 식물 이름/학명/기관 이름으로 검색하고 기록 목록 보기 전환 확인.
7. 메모만 수정하면 후보가 유지되고, 식물 이름을 바꾸면 미분류가 되는지 확인.
8. 다른 계정으로 바꾸었을 때 이전 계정의 집계·검색 내용이 남지 않는지 확인.
