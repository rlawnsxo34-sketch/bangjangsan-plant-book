ㅇㄱㅁㅇ v17 — 로그인 없이 시작하는 세 나무 관찰 체험

현재 버전 안내입니다. 이전 문서와 verification 파일은 각 버전의 참고 자료입니다.

1. 무엇을 추가했나요?
- 기관 선택 후 첫 화면이 ‘숲 관찰’로 열립니다.
- 편백나무·굴참나무·단풍나무의 짧은 설명과 관찰 질문을 제공합니다.
- 로그인과 사진 없이도 읽고 메모를 남길 수 있습니다.
- 나무를 관찰했다고 직접 표시하거나, 체크 없이 메모만 남길 수 있습니다.
- 세 종류를 모두 찾지 않아도 ‘내 관찰 요약’을 이용할 수 있습니다.
- 요약 내용을 한글 텍스트 파일(.txt)로 내려받을 수 있습니다. 이미지/PDF 카드 다운로드는 이번 버전에 포함하지 않았습니다.
- 식물 전체 대비 완성률이나 기관별 목표 종수는 없습니다.
- 대표사진은 추가 예정 안내로 표시합니다. 사진을 임의로 가져오거나 생성하지 않았습니다.
- ‘사진으로 알아보기’는 기존 사진 기록 화면으로 연결합니다. AI 분석과 계정 저장은 계속 이메일 로그인이 필요합니다.
- 체험 메모는 사진 기록으로 자동 복사되지 않습니다. 두 기록의 의미를 분리했습니다.

2. 현장 운영 상태를 정확히 표시합니다.
- 이 버전은 ‘장소 확인 전 시범 체험’입니다.
- 특정 기관에서 세 종류가 모두 관찰된다고 주장하지 않습니다.
- 실제 나무 위치, 탐방 동선, 방문 여부, AI/사용자의 종 판정을 인증하지 않습니다.
- 식물 설명은 출처를 참고하여 작성한 교육용 초안입니다. 현장 담당자의 최종 검토 전임을 표시합니다.
- 실제 관찰 위치와 담당자 검토가 완료되기 전에는 확정된 공식 탐방 코스로 홍보하지 마세요.
- 편백나무 표준명은 편백, 단풍나무는 Acer palmatum을 기준으로 작성했습니다. 당단풍나무 등 다른 수종이면 내용을 수정해야 합니다.
- 껍질을 벗기거나 가지·잎을 꺾지 않고 탐방로에서 관찰하도록 안내합니다.
- 식물의 건강·치료 효능이나 섭취 안내는 넣지 않았습니다.

3. 방문객 메모와 기존 계정 임시 기록의 차이
방문객 ‘숲 관찰’ 메모:
- 이 페이지의 메모리에만 있습니다. 서버·localStorage·IndexedDB에 쓰지 않습니다.
- 같은 기관에서 아래 메뉴를 이동했다가 돌아오면 메모가 남습니다.
- 페이지 새로고침, 창 닫기, 실제 다른 기관으로 변경, 로그인/로그아웃/계정 전환 시 사라집니다.
- 기관 변경 전에는 메모 초기화를 확인합니다. 로그인 상태 변경 시에는 초기화 안내를 표시합니다.
- 브라우저 종료 경고를 요청하지만 휴대폰 강제 종료 등에서는 경고가 나오지 않을 수 있습니다.
- 오래 보관하려면 ‘내 관찰 요약’ → ‘관찰 기록 내려받기 (.txt)’를 이용하세요.
- 다른 기기에서 동기화되지 않으며 계정 도감이나 공용 기록으로 자동 업로드되지 않습니다.
- 다운로드 파일에는 작성 메모와 선택한 기관명, 체험 시작일만 포함됩니다. 정확한 좌표·사진·계정 정보는 넣지 않습니다.
- 메모는 자유 입력이므로 이름·전화번호 등 개인정보를 적지 않도록 안내해주세요.

기존 로그인 후 ‘사진 기록’의 v16 임시 보관:
- 기존대로 계정과 기관별 기기 저장소에 임시 보관합니다.
- 7일 보관 정책과 복구·삭제, 계정 저장 후 정리 기능이 유지됩니다.
- 상세 내용은 DRAFT_RECOVERY_UPDATE.txt를 보세요.

4. 기관별 체험 링크와 QR 준비
예시 기관 문서 ID가 jangseong이라면:
https://plant-book-84803.web.app/?center=jangseong&view=explore

- jangseong은 예시입니다. 실제 forestCenters 문서 ID를 사용해야 합니다.
- 앱 ‘숲 관찰’ 아래의 ‘이 기관의 체험 링크 나누기’를 펼쳐 ‘체험 링크 복사’를 누르면 현재 선택한 기관 ID가 자동으로 들어갑니다.
- 복사가 지원되지 않으면 표시된 주소를 길게 누르거나 선택해 직접 복사하세요.
- 이 주소를 QR 코드에 넣으면 됩니다. QR 이미지 생성·인쇄는 이번 ZIP에 포함하지 않았습니다.
- 링크로 접속하면 등록 목록에서 활성 기관인지 확인한 뒤 바로 숲 관찰 화면을 엽니다.
- 미등록·비활성 기관이면 기관 선택 화면에 남습니다. 오류가 나면 목록 새로고침 후 확인하세요.
- 링크에 메모, 이메일, 인증 토큰을 넣지 않습니다. 링크는 기관 권한이나 실제 방문을 부여/인증하지 않습니다.
- 세 나무 콘텐츠는 공통 시범 콘텐츠입니다. 기관을 바꾸어도 그 기관 전용 해설로 바뀌지는 않습니다.
- 현장 수종·위치·내용 검토 전에는 위 링크를 내부 시험용으로 사용하세요.

5. Windows 적용 및 배포
(1) 기존 bangjangsan-plant-book 폴더 전체를 별도 폴더에 백업합니다.
(2) 이번 ZIP을 별도 임시 폴더에 압축 해제합니다.
(3) 프로젝트에 새 파일을 복사하되 기존 public-config.json과 .git 폴더는 유지합니다.
    node_modules와 backend/node_modules는 복사하지 않습니다.
(4) 프로젝트 루트의 cmd에서 실행합니다.
    cd /d "C:\Users\김준태\Documents\GitHub\bangjangsan-plant-book"
    npm ci
    npm test
    npm run build
    firebase deploy --only hosting --project plant-book-84803
(5) https://plant-book-84803.web.app 에서 새로고침하여 확인합니다.
(6) 정상 확인 후 GitHub Desktop에서 Commit → Push origin 합니다.

기존 v13 이후 Firestore 규칙과 v12 이후 Worker를 적용했다면 이번에는 Hosting만 배포합니다.
public-config.json, Firebase 규칙/인덱스, Cloudflare Worker·비밀 키·요금제는 변경할 필요가 없습니다.
Spark 요금제 구조를 유지합니다. Firebase init을 다시 실행하지 마세요.
인증서 설정이 필요했던 회사 PC에서는 같은 cmd 창에서 다음을 먼저 실행합니다.
    set "NODE_USE_SYSTEM_CA=1"
브라우저 데이터 삭제는 기존 기기 기록을 지울 수 있으므로 업데이트 방법으로 사용하지 마세요.

6. 사진을 나중에 추가하는 방법
먼저 직접 촬영 또는 허용된 사진을 준비하고 현장 담당자에게 수종을 확인하세요.
대표사진 한 장씩을 다음 이름으로 복사합니다. public/experience 폴더는 직접 생성합니다.
public/experience/hinoki.jpg
public/experience/cork-oak.jpg
public/experience/japanese-maple.jpg

src/experience-data.js에서 해당 나무의 photo:null을 아래와 같이 변경합니다.
photo:{src:'/experience/hinoki.jpg',alt:'촬영한 편백나무 가지와 잎',credit:'사진: 촬영자 또는 기관명 · 촬영일'}
다른 나무도 각자의 파일명과 설명으로 변경합니다.
사진 사용 허락 및 필요한 출처 표시를 확인하고 credit에 실제 정보를 적습니다.
경로·사진 설명·촬영 주체를 정확히 적고 npm run build 후 Hosting을 배포합니다.

location:null과 reviewed:false는 아직 확인하지 않았다는 표시입니다.
이를 true로 바꾸기만 해도 공식 검토로 인증되는 기능은 아닙니다.
실제 관찰 지점·검토자·검토 날짜 관리와 기관별 콘텐츠 운영은 후속 단계에서 구현해야 합니다.

7. 설명 자료 출처
- 편백: 산림청 산림용어사전 ‘편백’ 항목. 작은 비늘 모양 잎과 뒷면의 Y자 기공선에 관한 내용을 참고.
- 굴참나무: ‘굴참나무 - 한국민족문화대백과사전’, 집필 임경빈. 코르크층과 잎 뒷면 털에 관한 내용을 참고.
  https://encykorea.aks.ac.kr/Article/E0006759
- 단풍나무: 서울대공원 식물원 셀프 가이드 ‘단풍나무’. 잎 갈래와 학명을 참고.
  https://grandpark.seoul.go.kr/board/view/ko/S001003002007/B032.do?bbs_no=104314
- 외부 원문 사진은 사용하지 않았으며 설명은 짧은 관찰 활동용으로 새로 작성했습니다.
- 링크는 각 나무의 ‘설명 출처와 확인 상태’에서 확인할 수 있습니다. 외부 사이트 주소 변경 시 수정이 필요할 수 있습니다.

8. 휴대폰에서 확인할 것
- 로그아웃 상태에서 기관 선택 → 숲 관찰 설명 3개가 열리는지.
- 사진 없이 메모 한 줄만 작성해도 요약에 나타나는지.
- 체크와 메모가 독립적으로 유지되는지. 미체크 메모가 종 확인으로 표시되지 않는지.
- 텍스트 내려받기 후 브라우저 다운로드 목록에서 한글 내용이 보이는지.
- 사진 기록으로 이동하면 로그인 화면이 나오고, 로그인하지 않고 숲 관찰로 돌아오면 메모가 남는지.
- 로그인/로그아웃 시 방문객 메모가 초기화되고 안내가 표시되는지.
- 다른 기관으로 변경할 때 초기화 확인이 나오고 취소하면 메모가 유지되는지.
- 체험 링크를 복사해 새 탭에서 열었을 때 활성 기관만 바로 진입하는지.
- 기존 사진 분석·계정 도감·공유 도감·기기 도감·임시 기록 복구가 정상인지.

React 화면/흐름 테스트, 데이터 모델/링크 검증, 기존 71개 테스트와 빌드를 수행합니다.
